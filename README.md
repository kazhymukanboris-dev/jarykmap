# JarykMap

Interactive safety map of Astana for women (student MVP, Entrepreneurship final project, AITU CS-2417).

- Map: 2GIS MapGL JS API (a 2GIS key is entered in the app on first launch; it is not stored in this repository).
- Red markers: places reported as unsafe for pedestrians (unlit streets, underpasses, abandoned sites). Yellow: traffic-light problems. Green: lit, busy areas.
- Marker texts are short summaries of public media and akimat reports; coordinates are approximate.
- Green-area photos: Wikimedia Commons (free licences); author and licence are shown under each photo in the app.
- Installable as a web app (PWA): open the site in Safari → File → Add to Dock, or in Chrome → Install.
